    Offline Mode

    Create invoices and print PDFs even when internet is unstable.

    How offline access works
    Local browser storage

    Invoices, clients, business settings, logo, colors, and signature are saved in this browser so you can keep working on the same device.

    Print / save as PDF

    Open an invoice and use Print / Save PDF to create a copy you can send to customers.

    Sync comes later

    When Supabase is connected, accounts can sync across devices. Until then, data stays on the device/browser where it was created.
